# POL-11: method, coverage and published corrections

Keep the POL-8 content snapshot unchanged. Add a strict public companion file for
reviewed method sections, editorial responsibility/funding, independently sourced
collection/publication timestamps and explicitly published correction notices.
Bind that companion to the exact public dataset bytes. No draft or approval record
is a public field. An unavailable companion is allowed only for an empty production
dataset; a nonempty production dataset requires the reviewed publication material.

Use the POL-9 layout for method, coverage and correction routes. Derive coverage
from all current people/questions, reuse POL-10 coverage rendering and preserve
unknown dates rather than guessing from source dates, revisions or build time.
Correction notices resolve exact public versions and are not inferred from changes.

Prepare the actual French method copy separately in the private editorial repo,
with a version/hash for owner review. Use only fictional text in public test data.
Do not import or render the private drafts in the public checkout or its preview.

Sequence: contract/behavior tests; companion loader and generic components; private
review packet; integration/browser checks; independent review; code PR plus private
text PR. Neither PR is merged and no text is published without further approval.

Publication enforcement and collection automation remain POL-16/POL-17/POL-12.
This task cannot authenticate an owner approval or manufacture a successful run.
